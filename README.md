# 3D Faculty Campus

Responsive interactive campus model for the Faculty of Engineering at Kamphaeng Saen, Kasetsart University.

The web version preserves the supplied CampusResponsive model and application. Its embedded model is delivered as checksum-verified files under `assets/`, then loaded before the application starts.

## Run locally

Serve this directory with a static HTTP server and open `index.html`. Opening the hosted edition directly with `file://` will not load its separate assets.

## Hosting

Publish the repository root with a static hosting service such as GitHub Pages. The initial download is approximately 118 MB.

## Verification

See `upload-verification.json` for SHA-256 hashes and source-preservation checks.
